# Anthony Verruijt - Portfolio Website

Een moderne, responsive portfolio website gebouwd met Next.js en Tailwind CSS.

## ✨ Features

- **Responsive Design**: Werkt perfect op alle apparaten
- **Clean & Modern**: Minimalistische design geïnspireerd door top portfolios
- **Performance**: Geoptimaliseerd voor snelheid en SEO
- **Smooth Animations**: Subtiele animaties voor betere UX
- **Contact Form**: Werkende contact formulier
- **Dark/Light Theme**: Automatische theme detection

## 🚀 Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: Lucide React
- **Deployment**: Vercel

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 📝 Customization

1. **Content**: Update je persoonlijke informatie in de componenten
2. **Images**: Voeg je eigen foto's toe in de `public` folder
3. **Colors**: Pas het kleurenschema aan in `tailwind.config.ts`
4. **Contact**: Configureer je contact informatie en social links

## 📧 Contact Form Setup

Om het contact formulier werkend te krijgen, kun je integreren met:

- **EmailJS**: Voor client-side email sending
- **Netlify Forms**: Als je host op Netlify
- **Vercel Forms**: Als je host op Vercel
- **Custom API**: Eigen backend implementatie

## 🚀 Deployment

### Vercel (Recommended)

1. Push je code naar GitHub
2. Connect je repository op [vercel.com](https://vercel.com)
3. Deploy automatisch

### Netlify

1. Build command: `npm run build`
2. Publish directory: `out`
3. Enable static export in `next.config.js`
